# Версии

Каждое обновление программы получает новый номер версии. Прошлые версии не удаляются: у каждой есть тег `vX.Y`
и релиз на GitHub со сборками (Releases), так что к любой из них можно вернуться.

Как выпустить новую версию — раздел «Версии» в [ROADMAP.md](ROADMAP.md#версии). Номер стоит в пяти местах:
`desktop/package.json`, `web/app.js` (`APP_VERSION`), `web/help.js` (`VERSION`), `android/AndroidManifest.xml`
(`versionName` и `versionCode` на 1 больше прежнего) и заголовок раздела здесь. `tests/check_version.js` проверяет,
что они совпадают.

## 1.3 — 28.11.2026

- **Программа для Windows — один файл `halflife-calc-1.3.exe` около 7 МБ** вместо архива на 145 МБ: скачать
  и запустить, распаковывать и устанавливать ничего не нужно. Окно работает на движке Microsoft Edge (WebView2),
  который встроен в Windows 11 и в обновлённую Windows 10. Меню и горячие клавиши те же, что на сайте, «Открыть»
  и «Сохранить» — обычные окна Windows, файл `.hlc` можно перетащить на значок программы.
- **APK для Android теперь лежит в релизах на GitHub** рядом с остальными файлами, в том числе у версий 1.0–1.2.
  Его можно скачать прямо на телефон и установить поверх прежней версии.
- Прежняя большая сборка для Windows (Electron) остаётся в релизе запасным вариантом.

## 1.2 — 28.11.2026

- «Сколько было вначале?» можно задать не только активностью (Бк, Ки), но и **массой**: в списке «Единица» над
  таблицей — г, мг, мкг, нг, пг. Программа пересчитывает массу в активность (A = λ·m·N_A/M, атомные массы AME 2020).
- Тогда и результат — в массе: сколько граммов каждого изотопа осталось через выдержку, в том числе накопившихся
  стабильных. В массе же ответ «Коротко», график, Excel и протокол Word; столбец «Атомы и масса» показывает активность.
- Файл расчёта с массой хранит и активности в Бк, поэтому его верно откроет и версия 1.1.

## 1.1 — 27.11.2026

- Изотоп можно написать по-русски в каждом поле, где он выбирается: в шаге 1, в «Проверить чистоту» и в окнах
  «Подбор выдержки», «Пересчёт от измерения», «Масса и активность». Понимает «актиний-225», «225 актиния», «Ac225»,
  «радий» (если в расчёте один радий). Под полем — подсказки с русским названием и периодом полураспада.
- У каждого поля «Изотоп» — кнопка таблицы Менделеева, в том числе в меню «Инструменты». В окнах инструментов и
  в проверке чистоты в таблице можно выбрать только изотопы из расчёта, в «Массе и активности» — любой.
- Повторное нажатие по изотопу в таблице Менделеева снимает выбор: в шаге 1 убирает изотоп из расчёта, у поля —
  очищает его. Повторное нажатие по выбранному элементу снимает выбор элемента.
- На телефоне шириной 360 px шапка больше не раздвигает страницу.
- Номер версии и этот список изменений; прошлые версии со сборками остаются на странице Releases.

## 1.0 — 27.11.2026

Первая версия (коммит `a455279`, после PR #1–#14).

- Простой пошаговый интерфейс: изотоп → сколько было → сколько времени → результат. Ответ «Коротко», таблица,
  график, схема распада и формулы (текст, Maple, LaTeX, Python).
- Цепочки распада строятся сами по базе около 1250 радионуклидов (IAEA LiveChart, ICRP-107); свой T½ для любого изотопа.
- Ввод изотопа по-русски в шаге 1 («цезий-137») и таблица Менделеева.
- Готовые примеры, в том числе «Th-229 + Th-228 (как в расчётах заказчика)».
- Меню «Инструменты»: подбор выдержки, пересчёт от измерения, погрешность (Монте-Карло), масса и активность, генератор.
- Несколько сроков и расчёт по датам, проверка радионуклидной чистоты.
- Файлы расчёта `.hlc`, загрузка формул (Maple, LaTeX, Python, текст, CSV, Excel), экспорт в Excel, протокол Word, печать.
- Черновик и недавние расчёты, обновление данных IAEA.
- Веб-версия (в том числе GitHub Pages), Windows 10/11 и Android, всё работает без интернета.
