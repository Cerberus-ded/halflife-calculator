# Сборки для Android

Здесь лежат подписанные APK калькулятора полураспада: `apk/halflife-calc-X.Y.apk`, по одному на версию.
Ключ подписи в репозитории не хранится, поэтому APK собирают отдельно (`android/build.sh` в ветке `main`)
и кладут сюда. Все версии подписаны одним ключом, поэтому новая версия встаёт на телефон поверх прежней.

Отсюда APK попадает в релизы на странице [Releases](https://github.com/Cerberus-ded/halflife-calculator/releases):

- если APK положили до выпуска версии, его берёт `.github/workflows/release.yml` в `main`;
- если после, его прикрепляет к уже вышедшему релизу `.github/workflows/apk-to-release.yml` этой ветки.

Код приложения здесь не хранится: он в ветке `main`.
