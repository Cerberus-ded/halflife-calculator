> **Состояние на 27.11.2026.** Этот файл описывает первую ночь работы (три ветки: Дизайн, Код, Наполнение).

Язык интерфейса: русский. Пользователь — радиохимик. Всё работает офлайн (без интернета), одна кодовая база:
- **веб** — папка `web/`, открывается двойным кликом по `index.html` (file://) или с любого статического хостинга;
- **телефон** — та же веб-версия как PWA (manifest + service worker, «Установить на главный экран»);
- **десктоп (Windows)** — Electron-обёртка над `web/` в папке `desktop/`.

## Что делает программа (из голосовых/видео заказчика + уточнение)
1. Пользователь выбирает изотопы-родоначальники (например Th-229, Th-228; любые из базы ~1250 радионуклидов).
   Цепочки распада со всеми дочерними, ветвлениями и стабильными концами строятся **автоматически** из базы.
   Формулы вручную вводить не нужно.
2. Таблица исходных данных: список изотопов набора (пользователь сам строки не добавляет/не удаляет, только через
   родоначальников), колонка T½ (с источником), колонка **начальной активности в Бк** для каждого радиоактивного изотопа
   (по умолчанию 0) — это начальная концентрация примесей. Стабильные — без ввода.
3. Поле **«Выдержка»** (по умолчанию 7 сут; единицы: с, мин, ч, сут, лет).
4. Кнопка **«Расчёт»**: ввод блокируется (кнопка «Изменить данные» разблокирует), появляется таблица результата:
   A₀, A(t) в Бк, N(t) атомов (для стабильных — накопленные атомы), суммы по цепочкам; график A(t) (лог. шкала).
5. **Формулы видны всегда** и копируются: λ = ln2/T½ с числами, система ОДУ, начальные условия, аналитическое решение с
   коэффициентами, результат. Форматы: Текст, Maple (в стиле заказчика, см. фото в /mnt/project-files/photo_*.jpg), LaTeX, Python.
   Кнопка «Копировать» у каждого формата и «Скачать .txt/.mpl/.tex/.py».
6. Меню **Файл**: Новый, Открыть…, Сохранить, Сохранить как…, Экспорт в Excel (.xlsx). Сохраняется только ввод
   пользователя (родоначальники, активности, выдержка, правки T½). Формат файла — JSON, расширение `.hlc`.
7. Меню **Данные**: «Ядерные данные» (таблица набора: T½, λ, тип распада, доли ветвлений, источник; T½ можно
   переопределить, правки сохраняются в файл проекта и помечаются «польз.»), «Сбросить правки».
   Меню **Примеры**: готовые задачи (пресеты), в т.ч. «Th-229 + Th-228 (как в расчётах заказчика)».
   Меню **Справка**: «Как пользоваться», «О программе».
8. Горячие клавиши: Ctrl+N/O/S, Ctrl+Shift+S, Ctrl+E (экспорт), Enter в поле — расчёт.

## Готовые модули (не переписывать без согласования с координатором)
| файл | глобал | что |
|---|---|---|
| `web/nucdb.js` | `window.NUCDB` | база: `имя: [T½ сек или null, 'I'/'C'/'S', [[дочерний, доля, тип], …]]` |
| `web/core.js` | `window.HLCore` | `normalizeName(s)`, `nuclide(name, overrides)`, `buildSet(roots, overrides)` → массив нуклидов в топологическом порядке `{name,id,T,lambda,src,daughters,parents:[{name,j,br,mode}],root}`; `calculate(set, A0, tSec, points)` → `{rows:[{name,root,stable,lambda,T,src,A0,N0,N,A}], series:{t:[],A:[[]]}, coef, N0}`; `fmtHalfLife(T)`, `fmtNum(x,digits)`, `num(x)`, `units:{Y,D,H,MIN}` (год = 365,2422 сут) |
| `web/formulas.js` | `window.HLFormulas` | `text(m)`, `maple(m)`, `latex(m)`, `python(m)`, где `m = {set, A0, tSec, holdText, result?}` |
| `web/xlsx.js` | `window.HLXlsx` | `build([{name, rows, widths}])` → Blob .xlsx |

Точность ядра проверена против решения в 60 знаков (mpmath expm): отклонение < 3e-9 на цепочках U-238, U-235, Th-232,
Np-237, Cf-252, Th-229+Th-228 и др. `overrides` = `{ 'Th-229': {T: сек} }`.

## Мост Android (для app.js)
В APK страница работает в WebView из `file:///android_asset/www/`. Там нет File System Access API и не работают
скачивания `<a download>` и `navigator.clipboard`. Если есть `window.AndroidHost`:
- сохранение любого файла (.hlc, .xlsx, формулы): прочитать Blob в base64 (FileReader.readAsDataURL, взять часть после
  запятой) и вызвать `AndroidHost.saveFile(имя, mime, base64)` — откроется системный диалог «Сохранить как»;
- копирование текста: `AndroidHost.copyText(текст)`;
- открытие файла: обычный `<input type=file>` работает (системный выбор файла).
