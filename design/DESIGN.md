# Дизайн интерфейса: простая версия

Файлы дизайна: `web/index.html`, `web/style.css`, `web/icon.svg`, `web/icon-192.png`, `web/icon-512.png`,
`web/manifest.webmanifest`. Все id/классы/data-атрибуты из «Контракта DOM» в SPEC.md есть в разметке.
Старая «инженерная» версия (панели как в Maple/Excel) лежит в git-ветке `classic`.
Скриншоты (с настоящим app.js): `design/screens/`.

## Идея
Программа для человека, который видит её впервые. Страница — четыре пронумерованные карточки-шага:
1. **Какой изотоп считаем?** — поле `#rootInput` + «Добавить», чипы, кнопка «Готовые примеры» (меню с `#presetMenu`).
2. **Сколько было вначале?** — единица `#actUnit` (с расшифровкой: «МБк — миллионы Бк»), таблица `#inputTable`,
   под ней объяснение «период полураспада» и «стабильный».
3. **Сколько времени пройдёт?** — «Через [7] [суток]», большая кнопка «Рассчитать». Редкое («Ещё сроки», «По датам»,
   «Подобрать») свёрнуто в `<details id="holdMore">` «Дополнительно». После расчёта — зелёная плашка «Готово…».
4. **Результат** — заголовок `#resultTitle`, вкладки «Таблица / График / Формулы». Под таблицей — «как читать»
   (A₀, A(…), Сумма, запись 1,5E6). Столбец «число атомов» скрыт, пока не отмечено «Число атомов» (`#showAtoms`,
   только CSS). Проверка чистоты (`#purityBar`) свёрнута в `<details id="purityMore">`; итог `#purityOut` виден всегда.

Термины («активность», «беккерель», «период полураспада», «выдержка») объясняются там, где встречаются впервые.
Пункты меню «Файл», «Данные», «Справка» названы как в классической версии: на них ссылаются справка (help.js),
README и нативное меню Windows-версии.

## Как устроено
- Широкий экран (≥ 1100 px): шаги 1–3 слева (до 500 px), карточка «Результат» справа, прилипает к верху и занимает
  высоту окна; таблица, формулы и график прокручиваются внутри неё.
- Уже 1100 px: одна колонка до 800 px, страница листается. После расчёта в плашке «Готово» есть ссылка
  «Смотреть ответ ↓» (`a.to-result`). Таблицы на телефоне — от края до края карточки, первая колонка закреплена.
- Телефон (≤ 600 px): шрифт полей 16 px (иначе iOS увеличивает страницу), меню на всю ширину, название программы
  в шапке скрыто (остаётся значок). Проверено на 390 и 360 px без горизонтальной прокрутки.
- Electron (`body.electron`): HTML-шапка скрыта (меню нативное), остальное как в браузере.
- Меню «Примеры» теперь не в шапке, а в шаге 1: `.menu.examples-menu` с кнопкой «Готовые примеры».
  app.js привязывает все `.menu` на странице, поэтому оно работает как прежде.

## Какие состояния ставит app.js
| Что | Как | Примечание |
|---|---|---|
| Открытое меню | `.menu.open` (+ `aria-expanded="true"` у `.menu-btn`) | |
| Активная вкладка | `.tab.active` и `aria-selected="true"`; неактивные панели — атрибут `hidden` | |
| Выбранный формат | `.fmt.active` и `aria-pressed="true"` | |
| Ввод закреплён | `#inputPanel.locked`, `body.locked` или `disabled` у `#hold` | номера шагов 1–3 → зелёные галочки, видна плашка «Готово», поле ввода изотопа и «Дополнительно» прячутся, значения в таблице выглядят «напечатанными» |
| Пустые состояния | `#emptyState`, `#resultEmpty` | CSS сам прячет их, когда в `tbody` есть строки (`:has`); атрибут `hidden` тоже работает |
| Ошибка в поле | `input.invalid` или `aria-invalid="true"` | красная рамка; текст — в `#error` / `#rootError` |
| Скопировано | `button.done` / `button.failed` на 1–2 с | текст меняется в первом `<span>` кнопки |
| Несохранённые изменения | `#dirty` без `hidden` | янтарная точка у имени файла |
| До расчёта | `[data-needs-result]` в разметке `disabled` | |

## Заголовок «Было вначале»
`<th class="num"><span class="th-plain">Было вначале</span><span id="a0Head">A₀, Бк</span></th>` — app.js меняет
только текст `#a0Head`, простая подпись остаётся.

## Тесты и свёрнутые блоки
Поля внутри `<details>` («Ещё сроки», «По датам», «Подобрать», цель и предел чистоты) не видны, пока блок свёрнут.
Сценарии Playwright, которые их заполняют, раскрывают все блоки после загрузки страницы:
`await p.evaluate(() => document.querySelectorAll('details').forEach((d) => { d.open = true; }));`
(добавлено в `desktop/test/e2e-features.js` и `e2e-tools.js`). Видимость `#holdDates`, `#purityBar`, `#purityOut`
не зависит от свёрнутости.

## Цвета для canvas
Брать из CSS в момент рисования (тема может смениться):
```js
const cs = getComputedStyle(document.documentElement);
const v = (n) => cs.getPropertyValue(n).trim();
v('--chart-grid'); v('--chart-axis'); v('--chart-text'); v('--font-ui');
v('--series-' + (k % 8 + 1));   // k — порядковый номер кривой, цвет закреплён за изотопом
```
Палитра из 8 цветов проверена на различимость при дальтонизме в обеих темах. Холст лежит в `.chart-box` и занимает
его целиком. Пока в `#resultTable` нет строк, поверх холста CSS показывает «График появится после расчёта».

## Диалог `#dlg`
Шапка с заголовком и крестиком (`value="cancel"`), прокручиваемое тело `#dlgBody`, подвал с OK (`value="ok"`).
Стилизованы: `h3, p, ul, ol, code, kbd, table.grid` (в `.table-wrap`), `.note`, `.hint`, `p.msg`, `#dlg.wide`,
`.field-row`, `.date-grid`, `.find-grid`, `.find-conds`, `.find-out`, `.check-line`, `.iaea-link`, `.change-list`.
На телефоне кнопки подвала растягиваются и переносятся.
